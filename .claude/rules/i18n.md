# i18n mandatory

All user-visible text MUST go through vue-i18n. Never hardcode display strings.

- In `<script setup>`: `import { useI18n } from 'vue-i18n'` then `const i18n = useI18n()`.
- Template usage: `{{ i18n.t('key') }}` or `:label="i18n.t('key')"` (this project calls `i18n.t()`, not a destructured `t`).
- Keys live in `src/messages.json`, shape `{ "en": { ... }, "fr": { ... } }` (flat keys, no nesting).
- Every new key MUST be added to BOTH `en` AND `fr`.
- ⚠️ The `fr` locale is currently incomplete (empty/partial). When you touch i18n, restore parity — see the `translate` skill/agent.
